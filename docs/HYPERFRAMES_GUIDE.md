# Guiding HyperFrames for custom animation

`aes build` already generates footage, captions, kinetic text, transitions, music, SFX and the outro.
Write custom HyperFrames work only for graphics the plan cannot express (callouts, UI mockups,
arrows pointing at objects, charts, logo moments). This keeps tokens low and renders reliable.

## The rules
1. **Registry first.** Search before building: `npx hyperframes@0.9.1 catalog` or the
   `/hyperframes:hyperframes-registry` skill. Install into the project with
   `npx hyperframes@0.9.1 add <item>` run inside `projects/<name>/hf`.
2. **Write only between the CUSTOM markers** in `hf/index.html`:
   `/* CUSTOM-CSS-START */ ... /* CUSTOM-CSS-END */`, `<!-- CUSTOM-HTML-START --> ... <!-- CUSTOM-HTML-END -->`
   (inside `#overlays`), `// CUSTOM-JS-START ... // CUSTOM-JS-END` (the shared `tl` timeline is in scope).
   Everything else is regenerated by `aes build`; custom blocks survive rebuilds.
3. **Timing from the beat sheet.** Take start times from `timeline.json` (shot `start`/`end`, caption
   times). Every timed element needs `id`, `class="clip"`, `data-start`, `data-duration`. End an element
   about 0.004 s before a cut so no frame of it leaks into the next shot.
4. **Seek-safe GSAP only.** Add tweens to `tl` at absolute times (`tl.from("#x", {...}, 6.2)`).
   No `setTimeout`, no `Math.random`, no CSS animations that run on their own clock.
5. **Brand first.** Read the brand's `rules` and colours. Graphics never cover a face; check the
   shot's `caption_y` and face position in the frame sheet.
6. **Validate cheaply.** After editing: `.\aes.cmd build <name>` (re-lints), then
   `.\aes.cmd framesheet <name> --at <times of your graphic>`. Use
   `npx hyperframes@0.9.1 check` in `hf/` only when something looks wrong.
7. **Budget.** Light mode (standard): at most 2 custom graphics. Full mode (premium): as the brief needs.
   Quick mode: none.

## Useful HyperFrames skills
- `/hyperframes:hyperframes-animation`: motion rules, scene blueprints, 24 named text effects
- `/hyperframes:hyperframes-keyframes`: punch-ins, reframes, camera moves, masks
- `/hyperframes:hyperframes-registry`: about 450 ready blocks (transitions, overlays, charts, maps)
- `/hyperframes:hyperframes-audio`: advanced ducking and effects on placed audio
